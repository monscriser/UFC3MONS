Inside the current candidate

Progress, with the full picture.

01

Controller stability

R9 serializes input calls to address the vibration-related crash. The maintainer reports stable Reborn Career Mode on Windows and Linux on ROG Ally Z1 Extreme.

02

ROG Ally Z1 Extreme

Reborn Career Mode owner-tested at 60 FPS on Windows and Linux, with no gameplay bugs or texture errors observed in those sessions. Current engine timing stays at 60 FPS; broader validation continues.

03

Original edition: open issue

Original-game Career Mode still has graphics bugs, including an invisible opponent. Fixes are planned for future builds; R9 primarily focuses on Reborn.

04

Source & next steps

Launcher, integration code and SDK changes are public. These sources do not yet reproduce R9 alone. Read the build limitations or report an issue.

Development preview, not a validated stable release. Game data, generated game code, executables and personal saves are not distributed through this source repository. Console vsync remains enabled; the current shader mode is synchronous.
